Cách đưa build lên (git-based)

  1. Bỏ thư mục build WebGL vào games/<id>/ (có index.html).
  2. Ở bảng dưới, đổi trạng thái game đó sang available (hoặc dùng form thêm game mới).
  3. Bấm Export data/games.js → Copy → dán đè vào file data/games.js.
  4. Commit & git push lên nhánh main của repo survivor-web-hub. GitHub Pages tự build lại (~1 phút).

Trang admin này không có bảo mật thật (web tĩnh, không server) — ai có link đều xem được. Đừng đưa thông tin nhạy cảm vào đây.
