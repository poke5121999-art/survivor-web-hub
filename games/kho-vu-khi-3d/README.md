# Stylized weapons (three.js r170, code only)

72 weapons built entirely in code (no model or texture files) from the owner's two concept sheets:
58 on `ref/owner-weapons-sheet.png` (combat sheet) and 14 on `ref/owner-tools-sheet.png` (clean tools sheet).
Open `index.html` through any static server (ES modules need http). Click a weapon to inspect it.

## API

```js
import { weapons, byId } from './weapons/index.js';
import { inHand, gripWorld } from './lib/attach.js';

const g = byId['kitchen-knife'].build(seed = 1, { variant: 0 });   // THREE.Group, metres
scene.add(g);
inHand(g, rightHandBone, 'r', new THREE.Vector3(0, 0, 1));          // grip -> palm, forward -> aim
if (g.userData.weapon.grip2) leftHandTarget = gripWorld(g, 'grip2'); // two-handed weapons
```

`build(seed, opts)` returns a `Group` with one merged `Mesh` named `body` (one draw call, vertex colours + wear shader)
plus empty `Object3D` markers named `grip`, `grip2`, `muzzle`, `tip`, `edge`. `opts.variant`: `0` matches the sheet
(blood, rust as drawn), `1` is an alternate wear: no blood, heavier dirt and rust, saturated colours hue-shifted. `seed` moves the
rust, chips and blood mask.

### Metadata, `group.userData.weapon`

| field | meaning |
|---|---|
| `id, name, kind, hands, variant, seed` | `kind` is `melee`, `gun`, `shield` or `tool` |
| `tris, size` | triangle count, bounding size in metres |
| `grip` | `{pos, fwd, up}`, main-hand point. `fwd` points at the tip or muzzle, `up` toward the blade edge or gun top |
| `grip2` | same shape, off-hand point (two-handed weapons) |
| `muzzle` | `{pos, dir}` (guns) |
| `tip` | Vector3 (melee point) |
| `edge` | `{a, b}` segment along the cutting edge, for hit sweeps |

Frames: melee weapons stand along +Y (tip up, edge on +X, flat faces +/-Z). Guns lie along +X (muzzle +X, top +Y).
Origin is the butt/grip area; use `grip`, never the origin, to attach. `inHand` mirrors `up` for the left hand.

## Library (`lib/`)

* `kit.js` bevelled primitives, all in centimetres: `box`, `cyl`, `lathe`, `cone`, `blade` (extruded 2D outline with a
  chamfered edge strip, holes allowed), `tube` (sweep), `ring`, `gear` (gear or saw disc), `blob`, `hexRing`, `tape` (tilted
  wrap bands), `wire` (helix plus barbs), `nails` (scatter), `xf` (transform a group of parts), outline helpers `knifeOutline`,
  `teeth`, `arc`, `roundPoly`. Every part is painted with colour, material `t` (0 metal, 1 paint, 2 cloth, 3 wood), `stripe` (hazard)
  and a per-vertex `edge` flag for chipping.
* `wear.js` `makeWearMaterial()`: MeshStandardMaterial patched with `onBeforeCompile`: edge chipping, rust, dirt, blood
  splatter, hazard stripes, per-type metalness and roughness. Uniforms `uRust uDirt uChip uBlood uSeed`.
* `weapon.js` `weapon(id, name, def, fn)` defines a weapon and merges its parts into one geometry (then bakes cm to m).
  `def.fat = [x,y,z]` thickens parts after drawing; a part with `nofat: true` is skipped (round discs).
* `attach.js` `inHand`, `gripWorld`. `sheet-layout.js` is generated by `tools/crop.py` (cell rectangles and bounding boxes).

## Traced silhouettes (guns first)

`node tools/trace-profile.js [id]` reads `ref/cells/NN.png` and `tools/trace-config.json` and writes `lib/guns/<id>.json`,
`lib/guns/data.js` (what the build imports) and a debug overlay `ref/trace/<id>.png`. Per cell: background plane fit from the border,
threshold, close, fill holes, largest component, Moore contour trace, Douglas-Peucker (40-120 points for the whole outline, 20-70 per part).
Parts (stock, receiver, grip, magazine, barrel/handguard...) come from hand-picked cell-pixel rectangles in the config (first rectangle
claims its pixels); enclosed gaps (stock frame, D handle, trigger guard) become holes. Output is in cm, origin at the grip pixel.
`weapons/guns.js` extrudes each part (receiver 3.8 cm, stock 3.0, magazine 2.6, grip 3.0, barrel 3.4) and adds rails with ridges, sights,
trigger-guard rings, tape wraps, hazard stripes and decals as separate parts in the sheet's own pixel coordinates.
`weapons/traced.js` does the same for the throwing knives, kunai, karambit, kukri and frame saw. To re-trace after changing a rectangle,
edit the config and rerun the tool; the build stays code plus data.

## Add a weapon

1. Add to a file in `weapons/` (or a new one imported in `weapons/index.js`; array order = reference cell order):

```js
weapon('my-axe', 'My axe', { hands: 1, blood: 0.2, rust: 0.3, rot: 0 }, (k, variant) => {
  k.cyl(1.7, 1.5, 60, { col: 0x8a4a30, t: 3 });                    // handle, base at y=0
  k.blade([[-3,52],[-3,66],[9,70],[11,58],[9,48]], { d: 1.6, b: 0.4, col: 0xaab4bd, t: 0 });
  k.grip([0, 14, 0]); k.tip([11, 58, 0]); k.edge([11, 48, 0], [11, 70, 0]);
});
```
2. `rot` is the pose (deg, about Z) used only by the sheet layout. Add a cell to `ref/cells.json` and `lib/sheet-layout.js` if it should appear
   on a sheet. Run `node tools/ids.mjs` to refresh `ref/weapons.md`.

## Triangle budget

Measured (variant 0): total 34,208 tris for 72 weapons, average 475, min 64, max 1,628 (saw-blade bat). Typical knives 100-300,
bats, axes and tools 250-900, guns 500-1,360. Budget used while building: under 500 for hand props, under 1,500 for guns and heavy
props. One mesh and one material per weapon instance.

## Verification tools (`tools/`)

`compare.mjs` renders both layouts with the sheet camera and writes `shots/compare/NN.png` (reference left, ours right) plus
contact sheets `shots/compare/sheet-*.png`. `final.mjs` checks click-to-inspect, phone width, console errors. Both use Playwright with a local server
that exits on a timer.
