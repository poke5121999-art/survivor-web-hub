# Snail Ride - web remake (rev in version.json)

Browser remake of Snail Ride (com.bloop.snail 1.2, Bloop) built from the original APK's art, audio, fonts, scenes and the
decompiled game code. No Unity runtime: three.js r160 (vendor/) draws the 2D world, the UI is DOM.

- js/engine: assets.js (data/textures/localization), world.js (prefab -> scene graph, the game's shaders, 2D triggers),
  anim.js (decoded AnimationClips, legacy Animation, Animator state machines), particles.js (ParticleSystem/TrailRenderer),
  ui.js (Unity UI: RectTransform, Image, Text, Button, layout groups, ScrollRect).
- js/game: ports of the C# scripts (sceneGame, sceneMinigame, systems, uiScripts, uiMeta, audio, user/save).
- data/*.json, art/t/*.png, audio/*.mp3, art/fonts: generated by tools/ from the extraction in ~/snail-ride-ref:
  merge_splits.py -> dump_all.py (+inventory.py) -> export_audio.py + vgmstream -> export_art.py -> export_prefabs.py ->
  export_game.py -> export_misc.sh (mp3, font, lang) -> export_anim.py + animctl.py + combine_anim.py. Then stamp.py <rev>.
- Save: localStorage key snailride.user.v1 (UserData fields of the original).
- Tests: ../../test/run-all.sh (headless chromium via playwright-core).
