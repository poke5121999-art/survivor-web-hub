# Đấu Trường Thép

Real-time top-down 5v5 mech arena shooter. three.js r160 (vendored), ES modules, no build step, no asset files: geometry, textures and sound are generated by code.

## Layout

| File | Owns |
|---|---|
| `js/data.js` | Every tunable as tables: `MECHS`, `RULES`, `PICKUPS`, `PROPS`, `DIFFICULTY`, `TEAMS`, `REWARDS` |
| `js/maps.js` | Hand-written map layouts, `compileMap`, collision queries (`solidAt`, `castStatic`, `losClear`), `findPath` |
| `js/sim.js` | The match simulation. Pure, deterministic, 30 Hz. `createMatch`, `step`, `visibleTo`, `hidden`, `unitSpeed`, `summary` |
| `js/bots.js` | `botInput(m, u)`: one input per bot per tick. Pure, uses only `m.rng` for randomness |
| `js/main.js` | Boot, shared state `G`, main loop, URL params, test hooks |
| `js/gfx/*.js` | Renderer: textures, world, mechs, effects, post chain |
| `js/audio.js` | Synthesised sound and music |
| `js/ui.js`, `js/input.js`, `js/meta.js`, `css/ui.css` | HUD, menus, garage, input devices, save data |
| `tools/` | Node and Playwright checks |

## Rules that keep it testable and ready for online play

- `sim.js`, `maps.js`, `bots.js`, `data.js`, `rng.js` never import three.js or touch the DOM. They run in Node.
- All randomness in a match comes from `m.rng`. Same seed and same inputs give the same match.
- The renderer, audio and HUD only read match state and `m.events`. They never write to it.
- Angles are radians in the XZ plane, direction = `(cos a, sin a)`. +x is right on screen, +z is toward the camera (down on screen).

## Simulation contract

```js
const m = createMatch({ map: 'denrung', seed, roster });   // roster: [{ team: 0|1, mech, name, bot, diff }]
step(m, inputs);                                           // inputs[unit.id] = input
// input = { mx, mz, aim, fire, s1, s2, ult, heal, tx, tz }
//   mx, mz: move vector (-1..1)     aim: radians     tx, tz: world point under the cursor (ground-targeted skills)
//   fire, s1, s2, ult, heal: booleans, held is fine (cooldowns gate them)
```

Match `m`: `map, tick, time, target, duration, score[2], over, winner (-1 draw), units[], shots[], zones[], crates[], props[], events[]`.

Unit `u`: `id` (= index in `m.units`), `team, mech, def (MECHS row), name, bot, diff, radius, x, z, px, pz (previous tick), vx, vz, aim, heading, hp, maxHp, alive, respawnT, cd {fire, s1, s2, ult, heal}, shield, shieldMax, shieldT, slowT, slowF, stunT, hasteT, rapidT, dmgT, stealthT, invulnT, revealT, bush (-1 or bush id), cast (null or {skill, t, total, aim}), dash, kills, deaths, assists, dmg, healed, brain (free for bots.js)`.

Shot: `id, team, owner, x, z, px, pz, dx, dz, speed, left (range left), dmg, splash, r, vis`.

Zone: `id, kind ('strike' | 'mine' | 'field' | 'dome'), team, owner, x, z, r, age, delay, dur`, plus `total` (strike), `blast` (mine), `vis` ('heal' | 'slow', field).

Crate: `id, x, z, type (PICKUPS key), fall (> 0 while descending), age`.

Events (`m.events`, valid until the next `step`): `fire {id, vis, x, z, a, side}`, `skill {id, slot, skill, x, z, a}`, `impact {vis, on: unit|wall|prop|dome|end, x, z, dx, dz, splash}`, `hit {id, by, x, z, amt, absorbed}`, `heal {id, x, z, amt}`, `death {id, by, assists[], x, z}`, `respawn {id, x, z}`, `explode {x, z, r, why}`, `nova {id, x, z, r}`, `beam {id, x0, z0, x1, z1, w}`, `ram`, `shieldBreak`, `item {id}`, `zone`, `zoneEnd`, `propHit`, `propBreak {id, kind, x, z}`, `crateDrop {id, x, z, type}`, `crateLand`, `pickup {id, crate, type, x, z}`, `over {winner}`.

Map (`m.map`): `key, name, w, d, hw, hd, walls[{x0, x1, z0, z1, h, kind}], rounds[{x, z, r, kind}], bushes[{id, x, z, r}], props, cratePoints, bases[2] = [x, z], spawns[2], nav`.

## Shared state `G` (browser)

`G = { THREE, params, quality, bus, renderer, scene, camera, match, me, meta, audio, ui, input, gfx }`

- `G.bus.on(topic, fn)`, `G.bus.emit(topic, data)`. Topics: `sim` (each sim event, payload = event), `match:start`, `match:over`, `ui:play {mech, diff, map}`, `ui:menu`, `quality:set`.
- `G.match` is the current match or null. `G.me` is the id of the player's unit.
- `G.project(x, y, z)` → `{ x, y, visible }` in CSS pixels. `G.groundAt(clientX, clientY)` → `[x, z]` on the ground plane.
- `G.portrait(mechKey, team)` → data URL of a rendered mech portrait (128 px).

## URL params and test hooks

`?autostart` (skip menus, start a match), `?noaudio`, `?q=low|medium|high`, `?seed=N`, `?bots=easy|normal|hard`, `?mech=key`, `?map=key`, `?spectate` (the player slot is a bot too), `?manual` (the loop does not advance by itself; use `__step`).

`window.__G`, `__ready`, `__errors[]`, `__stats {fps, ms, calls, tris}`, `__step(n, draw)` (advance n sim ticks, draw once if `draw`), `__setShot({x, z, dist, pitch, yaw})` (pose the camera), `__input(fn | object | null)` (scripted player input: `fn(m, u) → input`), `__show(kind, key)` (showcase one mech, effect or map).
