Kingfall — WebGL build not dropped yet

This slot is wired up in the hub, but the game build is not here yet.

  1. In Unity, open thronefall-client/ and build the project for WebGL.
  2. Copy the build output (its index.html, Build/, TemplateData/, etc.) into web-hub/games/kingfall/, replacing this placeholder file.
  3. In web-hub/data/games.js, change the Kingfall entry's status from "build-pending" to "available".

Kingfall still ships the online stack it was built with (cloud save, ads, purchases, Google Play sign-in). It has not gone through the offline conversion Survivor did, so a WebGL build made today is not expected to run standalone yet.
